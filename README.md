# Sistema Gestor de Farmacias

## Descripción
Sistema para la gestión de inventario de productos farmacéuticos  y no farmacéuticos  [ropa y articulos de conveniencia para la salud] y ventas en farmacias.

## Tecnologías
- HTML
- CSS
- JS
- PHP
- PostgreSQL
- Bootstrap

- Desarrollo de la gestión de ventas de ropa en la Farmacia.
