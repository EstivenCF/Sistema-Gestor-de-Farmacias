# Sistema Gestor de Farmacias

## Descripción
Sistema web para la gestión de inventario de productos farmacéuticos y no farmacéuticos (ropa y artículos de conveniencia), así como el control de ventas en una farmacia.

## Funcionalidades principales
- Registro y gestión de productos
- Control de inventario
- Registro de ventas
- Sistema básico de seguridad

## Tecnologías
- HTML
- CSS
- JavaScript
- PHP
- PostgreSQL
- Bootstrap
